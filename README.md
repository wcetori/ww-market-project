# WW MARKET PROJECT

Адаптивний демонстраційний магазин.

## Запуск

Відкрийте `index.html` у сучасному Chrome, Edge, Firefox або Safari. Збірка та встановлення пакетів не потрібні.

## Структура

```text
index.html                        Семантична розмітка сторінки
credits.html                      Автори, джерела й ліцензії фотографій
PHOTO_LICENSES.md                 Перелік фотоліцензій для GitHub
THIRD_PARTY_NOTICES.md            Межі прав на фото, логотип і код
ww-logo.svg                       Векторний логотип
assets/
  css/styles.css                  Дизайн, компоненти, адаптивність
  images/hero-device.svg          Локальна ілюстрація для банера
  images/product-placeholder.svg Резервне зображення товару
  images/products/                92 оптимізовані WebP-файли (46 × 2)
  images/photo-sources.json       Відповідність фото товарам
  images/photo-licenses.json      Авторство, ліцензії, зміни, SHA-256
  images/photo-source-metadata.json Знімок метаданих джерел
  js/products.js                  Дані каталогу й характеристики
  js/core.js                      Фільтрація, розрахунки, перевірка сховища
  js/ui.js                        SVG-іконки, діалоги, сповіщення
  js/catalog.js                   Каталог, фільтри, картки та деталі
  js/cart.js                      Кошик, обране, оформлення, історія
  js/account.js                   Локальні демо-акаунти й відновлення
  js/app.js                       Ініціалізація та обробники подій
scripts/server.mjs                Сервер лише для локальної розробки
scripts/prepare-photos.py         Повторювана оптимізація фотографій
scripts/build-photo-credits.mjs   Генератор сторінки атрибуції
tests/core.test.cjs               Перевірки логіки та збереження
tests/photos.test.cjs             Перевірки ліцензій і локальних файлів
tests/browser.mjs                 Наскрізні перевірки у Chrome/Edge
```

Скрипти завантажуються послідовно через `defer` і використовують єдиний простір імен `WW`. Це дозволяє відкривати сторінку без сервера та зберігає розподіл відповідальності між файлами. Обробників `onclick` і вбудованих стилів у HTML немає; дії підключені через `addEventListener` та `data-action`.

## Можливості

- Пошук під час введення за назвою, брендом, категорією та характеристиками; кілька слів у довільному порядку.
- Фільтри категорії, бренду, діапазону цін, рейтингу та знижок. Активні фільтри можна прибирати окремо.
- Сортування за популярністю, ціною, рейтингом і розміром знижки; завантаження наступних 12 товарів.
- Деталі товарів із характеристиками, ціною й керуванням обраним.
- Обране, кошик, зміна кількості, видалення, підрахунок суми та економії. До 99 одиниць одного товару.
- Гостьове оформлення з перевіркою контактів, історія локальних замовлень і повторне додавання товарів за поточними цінами.
- Реєстрація, перевірка пароля, вихід і відновлення пароля за особистим кодом.
- Обране окреме для кожного акаунта: додавання доступне після входу. Вихід приховує список, повторний вхід відновлює його; інший акаунт має власну добірку.
- Збереження кошика й обраного після перезавантаження, синхронізація їхніх змін між вкладками одного сайту.
- Валідація даних зі сховища, відновлення після пошкодженого JSON; перенесення старого `ww_cart`. Старі спільні `ww_favs` збережені як резерв у даних, але не прив’язуються автоматично до акаунта, оскільки їхній власник невідомий.
- Доступні діалоги: Escape, закриття натисканням поза вікном, обмеження Tab усередині, повернення фокуса.
- Мобільні фільтри, адаптивна сітка, підтримка зменшеного руху, резервне зображення при недоступності фото.

## Межі демонстрації

Це **браузерна демонстрація, а не готовий магазин для реальних продажів**:

- Немає сервера, API, бази даних, реальних оплат, поштових повідомлень або доставки.
- Ціни, характеристики, оцінки й кількість оцінок ілюстративні. Фото з Wikimedia Commons справжні, але частина старих позицій використовує фото спорідненої моделі; це явно позначено в картці й деталях. Для реального продажу потрібні фото точної комплектації та актуальні дані продавця.
- У `localStorage` під ключем `ww_market_v2` зберігаються кошик, обране, демо-акаунти та до 100 останніх замовлень. Ім’я, контакти та адреса демо-замовлення зберігаються локально — використовуйте тестові дані.
- Паролі не зберігаються відкритим текстом: використано Web Crypto PBKDF2-SHA-256, випадкову сіль і 210 000 ітерацій. Код відновлення теж зберігається як хеш. Це не забезпечує серверної авторизації: власник браузера може редагувати локальні дані.
- Код відновлення показується один раз після реєстрації. Лист із кодом не надсилається. Без збереженого коду відновлення доступу не виконується.
- Сесія акаунта зберігається в `sessionStorage`. Історія гостьових замовлень відокремлена від замовлень, створених після входу.
- Старий `ww_user` не переноситься: попередня версія не перевіряла паролі. Створіть новий тестовий акаунт.
- Якщо локальне сховище заблоковано, каталог і кошик працюють у пам’яті поточної сторінки. Зміна обраного, реєстрація й створення замовлення покажуть помилку; попереднє обране й кошик не втрачаються при невдалому збереженні.

Для реального магазину потрібно окремо реалізувати серверну авторизацію, базу даних, перевірку цін і залишків на сервері, поштовий сервіс та платіжну інтеграцію.

## Перевірки

```sh
npm test
npm run test:browser
```

Другий скрипт потребує встановленого Chrome або Edge. За потреби вкажіть шлях у змінній `BROWSER_PATH`. Він запускає прихований браузер з окремим тимчасовим профілем, тому ваші акаунти, вкладки та дані не використовуються.

Перевіряються фільтри, сортування, кошик, оформлення, локальні акаунти, відновлення пароля, пошкоджене сховище, фокус клавіатури й ширини екрана 320 / 390 / 768 / 1440 px. Знімки сторінки зберігаються в `tests/artifacts/` і не додаються до Git.

## Як змінювати

- **Товари:** редагуйте `assets/js/products.js`. `id` має бути унікальним і незмінним; `cat` має відповідати категоріям у `core.js`.
- **Кольори й розміри:** змінні на початку `assets/css/styles.css`; адаптивні правила наприкінці.
- **Поведінка:** відповідний файл у `assets/js/`; нові дії підключайте в таблиці `actions` у `app.js`.
- **Текст від користувача:** перед вставленням у HTML використовуйте `WW.ui.escape` або `textContent`.

## Фото та оптимізація

Усі фото товарів завантажуються з цього репозиторію; запитів до Unsplash чи Wikimedia під час користування магазином немає. Для кожного фото є WebP 480 × 360 і 960 × 720 px, `srcset`, `sizes`, розміри для стабільної верстки та відкладене завантаження. Сумарний розмір фотографій — приблизно 3.1 MiB. Дрібні прев’ю використовуються в картках, більші — коли цього потребує розмір екрана та щільність пікселів.

Авторство доступне через «Автор і ліцензія» в кожній картці та посилання в підвалі. Сторінка `credits.html` працює без JavaScript. Фото не обрізані: пропорції збережені, до формату 4:3 додані нейтральні поля. Код підготовки видаляє EXIF, а юридично важливі відомості зберігає в супровідних файлах.
